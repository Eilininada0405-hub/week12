# Week 12 ポートフォリオ

## 制作物

独立した新規フォルダに1ページのポートフォリオサイトを作成しました。

- HTML: [portfolio/index.html](portfolio/index.html)
- 使用技術: HTML / Tailwind CSS CDN / Splide CDN / CSSアニメーション
- セクション: ヘッダー、自己紹介、スキルリスト、作品スライダー、フッター

## アニメーション

- ヘッダーのContactボタン: `hover:-translate-y-1` と `transition-all duration-300` で浮き上がる表現
- 作品カード: `hover:-translate-y-2` と `transition-all duration-500` でカード全体を浮かせる表現
- 作品画像: `group-hover:scale-110` と `transition-all duration-500` で画像を拡大
- 作品サムネイル: `group-hover:opacity-100` で「詳細を見る」オーバーレイを表示

## Splideの設定

`type: 'loop'`、`autoplay: true`、`interval: 4200`、`pauseOnHover: true` を設定しました。
作品を途切れなく見られるようにループさせ、一定時間ごとに自動再生しつつ、内容を読みたいときはホバーで停止できるようにしました。PCでは2枚、768px未満では1枚を表示します。

## 判断の記録

- 選択肢A: スライダーを自動再生する
- 選択肢B: 自動再生せず手動でめくる
- 採用した理由: 作品一覧に動きを加え、最初の画面で複数作品の存在を伝えたかったため。ただし、`pauseOnHover` を有効にして読みやすさも確保しました。
- 確認方法: Splideの矢印・ページネーション・自動切り替えをブラウザで確認します。

## 確認結果

- 375px: 1カラム表示、作品スライダーは1枚表示になるレスポンシブ設定
- 1280px: ヒーローと本文が2カラム、作品スライダーは2枚表示になる設定
- HTMLの静的エラーチェック: エラーなし
- 外部画像とCDNを使用しているため、ブラウザ確認時はインターネット接続が必要
